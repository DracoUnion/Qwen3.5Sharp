# 第 13 章 让文字进得去出得来：字节级 BPE 与聊天模板

> 代码锚点贯穿正文。核心文件：`src/Qwen35Sharp.Model/BpeTokenizer.cs`、`ChatTemplate.cs`。

模型的四层引擎都齐了——token 进、logits 出。但用户接触的永远是最外围两层：文字↔token 的分词器，与"怎么组织输入消息"的聊天模板。这一章把引擎变成"能受理中文对话的程序"，全程由 GGUF 的 `tokenizer.ggml.*` 元数据驱动。

## 13.1 预拆分特殊 token：别让 `<|assistant|>` 被 BPE 撕碎

字节级 BPE 对普通文字有效，但对**特殊 token**致命——模型把特殊 token 当一整块看，而 BPE 合并很可能把它们拆碎。`src/Qwen35Sharp.Model/BpeTokenizer.cs` 的构造函数先收集 `_specialIds`：

```csharp
public BpeTokenizer(GgufFile gguf)
{
    string[] tokens = gguf.GetStringArray("tokenizer.ggml.tokens");
    _idToToken = tokens;
    _tokenToId = new Dictionary<string, int>(tokens.Length, StringComparer.Ordinal);
    for (int i = 0; i < tokens.Length; i++) _tokenToId.TryAdd(tokens[i], i);

    _merges = new Dictionary<string, int>(StringComparer.Ordinal);
    string[] merges = gguf.GetStringArray("tokenizer.ggml.merges");
    for (int i = 0; i < merges.Length; i++) _merges.TryAdd(merges[i], i);

    BosId = gguf.GetInt32("tokenizer.ggml.bos_token_id", 0);
    EosId = gguf.GetInt32("tokenizer.ggml.eos_token_id", 0);
    UnkId = gguf.GetInt32("tokenizer.ggml.unknown_token_id", 0);

    int[] tokenTypes = gguf.GetInt32Array("tokenizer.ggml.token_type");
    _specialIds = new HashSet<int>();
    for (int i = 0; i < tokens.Length; i++)
    {
        bool typed = i < tokenTypes.Length && (tokenTypes[i] == 3 || tokenTypes[i] == 4);
        if (typed || i == BosId || i == EosId) _specialIds.Add(i);
    }

    string pre = gguf.GetString("tokenizer.ggml.pre", "gpt2");
    _pretokenizer = new Regex(ResolvePreTokenizer(pre), RegexOptions.Compiled);
}
```

`Encode` 里把特殊 token 从原文先切出来（`fragments` 列表，普通片段带 `null`、特殊片段带预设 id）：

```csharp
public int[] Encode(string text)
{
    List<(string Text, int[]? Ids)> fragments = [(text, null)];
    // Pre-split known special tokens so they survive BPE merging.
    foreach (int id in _specialIds)
    {
        string special = _idToToken[id];
        if (special.Length == 0) continue;
        List<(string Text, int[]? Ids)> next = [];
        foreach ((string frag, int[]? presetIds) in fragments)
        {
            if (presetIds != null) { next.Add((frag, presetIds)); continue; }
            int start = 0;
            while (true)
            {
                int idx = frag.IndexOf(special, start, StringComparison.Ordinal);
                if (idx < 0)
                {
                    if (start < frag.Length) next.Add((frag[start..], null));
                    break;
                }
                if (idx > start) next.Add((frag[start..idx], null));
                next.Add((special, [id]));
                start = idx + special.Length;
            }
        }
        fragments = next;
    }

    List<int> ids = [];
    foreach ((string frag, int[]? preset) in fragments)
    {
        if (preset != null) { ids.AddRange(preset); continue; }
        foreach (Match match in _pretokenizer.Matches(frag))
        {
            string normalized = ByteEncode(match.Value);
            if (_tokenToId.TryGetValue(normalized, out int direct)) ids.Add(direct);
            else ids.AddRange(Bpe(normalized));
        }
    }
    return [.. ids];
}
```

## 13.2 预分词与字节编码：一统中文与英文

**预分词**：`ResolvePreTokenizer`（Qwen/GPT-2 风格正则）：

```csharp
internal static string ResolvePreTokenizer(string preTokenizerType) => preTokenizerType switch
{
    // Qwen / GPT-2 style: standard byte-level BPE pretokenizer.
    _ =>
        @"'s|'t|'re|'ve|'m|'ll|'d| ?\p{L}+| ?\p{N}+| ?[^\s\p{L}\p{N}]+|\s+(?!\S)|\s+",
};
```

**字节编码**：`ByteEncode`/`EncodeByte` 把 UTF-8 字节映射到可见字符区间——

```csharp
private static char EncodeByte(byte b)
{
    if (b == 0xAD) return (char)0x0143;
    if (b <= 0x20) return (char)(b + 0x0100);        // 控制符挪到高位区
    if (b >= 0x7F && b <= 0xA0) return (char)(b + 0x00A2);
    return (char)b;
}
```

**BPE 合并**：`Bpe(token)` 按 merges rank 反复找最小可合并对——

```csharp
private List<int> Bpe(string token)
{
    if (token.Length == 0) return [];
    List<string> word = new(token.Length);
    for (int i = 0; i < token.Length; i++) word.Add(token[i].ToString());

    while (word.Count > 1)
    {
        int best = int.MaxValue; int bestIndex = -1;
        for (int i = 0; i < word.Count - 1; i++)
            if (_merges.TryGetValue(word[i] + " " + word[i + 1], out int rank) && rank < best)
                { best = rank; bestIndex = i; }
        if (bestIndex < 0) break;
        word[bestIndex] += word[bestIndex + 1];
        word.RemoveAt(bestIndex + 1);
    }

    List<int> ids = new(word.Count);
    for (int i = 0; i < word.Count; i++)
        ids.Add(_tokenToId.TryGetValue(word[i], out int id) ? id : UnkId);
    return ids;
}
```

`_merges` 是 `Dictionary<string,int>`——键 `"a b"`、值 = 训练时 rank（数组下标）。找不到回退 `UnkId`。

## 13.3 Decode 与增量流式：把 id 还原成可显示的文字

```csharp
public string Decode(IReadOnlyList<int> ids)
{
    List<byte> bytes = new(ids.Count);
    for (int i = 0; i < ids.Count; i++)
    {
        int id = ids[i];
        if ((uint)id >= (uint)_idToToken.Length) continue;   // 越界 id 跳过
        AppendTokenBytes(_idToToken[id], bytes);
    }
    return Encoding.UTF8.GetString(bytes.ToArray());
}

public string DecodeVisible(IReadOnlyList<int> ids) => Decode(ids);
public bool IsStop(int id) => id == EosId || id < 0;
```

`AppendTokenBytes` 是 `EncodeByte` 的逆映射（0x0120→0x20、0x0143→0xAD、0x0121..0x0142→0x7F..0xA0…），末尾交给 `Encoding.UTF8.GetString`。`DecodeVisible` 的存在意义在 CLI 流式（第 14 章）：增量 diff 打印需要"已可见文本"的稳定基准。

## 13.4 Qwen3.5 聊天模板：把消息拼成模型期待的格式

`src/Qwen35Sharp.Model/ChatTemplate.cs` 的 `RenderQwen35` 按角色拼模板（真实代码）：

```csharp
public static string RenderQwen35(
    IReadOnlyList<ChatMessage> messages,
    bool addGenerationPrompt = true,
    bool enableThinking = true)
{
    StringBuilder sb = new();
    int startIdx = 0;
    if (messages.Count > 0 && messages[0].Role == "system")
    {
        sb.Append("<|system|>\n");
        sb.Append(messages[0].Content.Trim());
        sb.Append("\n<|/system|>\n");
        startIdx = 1;
    }

    for (int i = startIdx; i < messages.Count; i++)
    {
        ChatMessage msg = messages[i];
        if (msg.Role == "user")
        {
            sb.Append("<|user|>\n");
            sb.Append(msg.Content.Trim());        // user 要 Trim
            sb.Append("\n<|/user|>\n");
        }
        else if (msg.Role == "assistant")
        {
            sb.Append("<|assistant|>\n");
            sb.Append(msg.Content);               // assistant 不 Trim！
            sb.Append("<|/assistant|>\n");
        }
    }

    if (addGenerationPrompt)
    {
        sb.Append("<|assistant|>\n");
        if (enableThinking) sb.Append(" thinking\n");
        else                sb.Append(" thinking\n\n response\n\n");   // 空思考块
    }
    return sb.ToString();
}
```

`ChatMessage` 是 `readonly record struct ChatMessage(string Role, string Content)`。三个细节：**user 要 Trim、assistant 不 Trim**；**生成提示 `<|assistant|>\n thinking\n`**；**模板是纯文本**（无视觉占位）。

CLI 每次多轮把历史 `messages` 重新 `RenderQwen35` 再 `Tokenizer.Encode`——"历史即上下文"，也是 `KvCacheAlign`（第 10 章）前缀复用的原因。

> **一句话总结这一章**：`BpeTokenizer` 用特殊 token 预拆分、预分词正则（`ResolvePreTokenizer`）、字节编码（`ByteEncode`/`EncodeByte`）、BPE 合并（`Bpe`）把文字可靠地编成 token id、再 decode 回来（`Decode`/`AppendTokenBytes`）；`ChatTemplate.RenderQwen35` 把消息拼成 `<|system|>/<|user|>/<|assistant|>` 结构并加生成提示。文字通了——只剩最后一件事：把一切装进能交互的程序，让模型真正开口说话。第 14 章，CLI 与自回归生成循环。
