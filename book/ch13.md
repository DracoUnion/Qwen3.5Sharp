# 第 13 章 让文字进得去出得来：字节级 BPE 与聊天模板

> 面向初学者：本章讲"文字 ↔ 数字"的翻译官（分词器），和"消息怎么组织成语境"（聊天模板）。用贴 `src/Qwen35Sharp.Model/BpeTokenizer.cs`、`ChatTemplate.cs` 的**真实源码**并配图把流程讲透。

模型的四层引擎都齐了——token 进、logits 出。但用户接触的是最外围两层：**文字↔token** 的分词器，与"怎么组织输入消息"的聊天模板。这一章把引擎变成"能受理中文对话"的程序。

## 13.1 预拆分特殊 token：别让 `<|assistant|>` 被 BPE 撕碎

先认识一个容易被忽视、却最致命的问题。

模型认识的最小单位叫 **token**，可以理解成"半个词"（中文通常一个字甚至更细）。分词器的作用，就是把整段文字切成一串 token 编号。它有个隐藏的雷：**特殊 token**。像 `<|system|>`、`<|assistant|>`、`<|endoftext|>` 这种由尖括号和英文组成的标记，模型在训练时是**当作一整块**对待的；而分词器的合并规则（BPE）是按搭配频率学的，**很可能把它们拦腰切开**——比如把 `<|assistant|>` 切成了碎片。

喂碎片给模型，等于输入了它训练时从没见过的东西，对话结构就会乱。

项目解决方式：**先把特殊 token 从原文里"摘"出来，剩余部分再做 BPE**。`BpeTokenizer` 的构造函数先收集体 `_specialIds`（真实代码，带注释）：

```csharp
public BpeTokenizer(GgufFile gguf)
{
    string[] tokens = gguf.GetStringArray("tokenizer.ggml.tokens");   // token 表
    _idToToken = tokens;
    _tokenToId = new Dictionary<string, int>(tokens.Length, StringComparer.Ordinal);
    for (int i = 0; i < tokens.Length; i++) _tokenToId.TryAdd(tokens[i], i);  // 反向字典

    _merges = new Dictionary<string, int>(StringComparer.Ordinal);   // 合并表："a b" → rank
    string[] merges = gguf.GetStringArray("tokenizer.ggml.merges");
    for (int i = 0; i < merges.Length; i++) _merges.TryAdd(merges[i], i);

    BosId = gguf.GetInt32("tokenizer.ggml.bos_token_id", 0);
    EosId = gguf.GetInt32("tokenizer.ggml.eos_token_id", 0);
    UnkId = gguf.GetInt32("tokenizer.ggml.unknown_token_id", 0);

    // 特殊 token 集合：token_type ∈ {3,4} 或等于 bos/eos 的 id
    int[] tokenTypes = gguf.GetInt32Array("tokenizer.ggml.token_type");
    _specialIds = new HashSet<int>();
    for (int i = 0; i < tokens.Length; i++)
    {
        bool typed = i < tokenTypes.Length && (tokenTypes[i] == 3 || tokenTypes[i] == 4);
        if (typed || i == BosId || i == EosId) _specialIds.Add(i);
    }

    string pre = gguf.GetString("tokenizer.ggml.pre", "gpt2");
    _pretokenizer = new Regex(ResolvePreTokenizer(pre), RegexOptions.Compiled);
}
```

`Encode` 里把特殊 token 先切出来（`fragments` 列表：普通片段标记为 `null` 待 BPE，特殊片段带预设 id）：

```csharp
public int[] Encode(string text)
{
    List<(string Text, int[]? Ids)> fragments = [(text, null)];   // 起初整段未处理
    foreach (int id in _specialIds)                                // 逐个特殊 token 切分
    {
        string special = _idToToken[id];
        if (special.Length == 0) continue;
        List<(string, int[]?)> next = [];
        foreach ((string frag, int[]? presetIds) in fragments)
        {
            if (presetIds != null) { next.Add((frag, presetIds)); continue; }
            int start = 0;
            while (true)
            {
                int idx = frag.IndexOf(special, start, StringComparison.Ordinal);
                if (idx < 0) { if (start < frag.Length) next.Add((frag[start..], null)); break; }
                if (idx > start) next.Add((frag[start..idx], null));   // 前面普通段
                next.Add((special, [id]));                              // 特殊段带预设 id
                start = idx + special.Length;
            }
        }
        fragments = next;
    }

    List<int> ids = [];
    foreach ((string frag, int[]? preset) in fragments)
    {
        if (preset != null) { ids.AddRange(preset); continue; }        // 特殊段直接用预设 id
        foreach (Match match in _pretokenizer.Matches(frag))
        {
            string normalized = ByteEncode(match.Value);
            if (_tokenToId.TryGetValue(normalized, out int direct)) ids.Add(direct);  // 整词命中
            else ids.AddRange(Bpe(normalized));                                        // 否则 BPE 合并
        }
    }
    return [.. ids];
}
```

## 13.2 预分词与字节编码：一统中文与英文

特殊 token 切走后，普通文本按三小步进入 BPE 管道。

**预分词**：用正则把句子切成"词素"。`ResolvePreTokenizer`（Qwen/GPT-2 风格）：

```csharp
internal static string ResolvePreTokenizer(string preTokenizerType) => preTokenizerType switch
{
    // Qwen / GPT-2 style: standard byte-level BPE pretokenizer.
    _ => @"'s|'t|'re|'ve|'m|'ll|'d| ?\p{L}+| ?\p{N}+| ?[^\s\p{L}\p{N}]+|\s+(?!\S)|\s+",
};
```

大白话解读：一是英文缩写（`'s`、`'t`…）；二是字母串（可带前导空格，` ?\p{L}+`）；三是数字串；四是其它标点串；五是空白。` ?\p{L}+` 里的前导空格，正是"词前的空格能合进 token"的物理基础——这让中文、英文、混排统一走同一条管道。

**字节编码**：`ByteEncode`/`EncodeByte` 把 UTF-8 字节映射到"可打印字符区间"：

```csharp
private static char EncodeByte(byte b)
{
    if (b == 0xAD) return (char)0x0143;            // 软连字符挪开
    if (b <= 0x20) return (char)(b + 0x0100);      // 控制符挪到高位区（可打印）
    if (b >= 0x7F && b <= 0xA0) return (char)(b + 0x00A2);  // DEL 区挪开
    return (char)b;
}
```

**BPE 合并**：`Bpe(token)` 按 merges rank 反复找最小可合并对（真实代码）：

```csharp
private List<int> Bpe(string token)
{
    if (token.Length == 0) return [];
    List<string> word = new(token.Length);
    for (int i = 0; i < token.Length; i++) word.Add(token[i].ToString());   // 先拆成单字符

    while (word.Count > 1)
    {
        int best = int.MaxValue; int bestIndex = -1;
        for (int i = 0; i < word.Count - 1; i++)
            if (_merges.TryGetValue(word[i] + " " + word[i + 1], out int rank) && rank < best)
                { best = rank; bestIndex = i; }     // 找 rank 最小的相邻对
        if (bestIndex < 0) break;                   // 没有可合并对就停
        word[bestIndex] += word[bestIndex + 1];     // 合成一个
        word.RemoveAt(bestIndex + 1);
    }

    List<int> ids = new(word.Count);
    for (int i = 0; i < word.Count; i++)
        ids.Add(_tokenToId.TryGetValue(word[i], out int id) ? id : UnkId);   // 找不到用 UNK
    return ids;
}
```

`_merges` 是 `Dictionary<string,int>`——键 `"a b"`、值 = 训练时 rank（数组下标）。rank 越小越该先合。

## 13.3 Decode 与增量流式：把 id 还原成可显示的文字

```csharp
public string Decode(IReadOnlyList<int> ids)
{
    List<byte> bytes = new(ids.Count);
    for (int i = 0; i < ids.Count; i++)
    {
        int id = ids[i];
        if ((uint)id >= (uint)_idToToken.Length) continue;   // 越界 id 跳过
        AppendTokenBytes(_idToToken[id], bytes);             // 反向字节映射
    }
    return Encoding.UTF8.GetString(bytes.ToArray());         // 字节 → 文本
}

public string DecodeVisible(IReadOnlyList<int> ids) => Decode(ids);
public bool IsStop(int id) => id == EosId || id < 0;         // 停止判定
```

`AppendTokenBytes` 是 `EncodeByte` 的逆映射（0x0120→0x20、0x0143→0xAD…），末尾交给 `Encoding.UTF8.GetString`。`DecodeVisible` 的意义在 CLI 流式（第 14 章）：增量 diff 打印需要"已可见文本"的稳定基准。

## 13.4 Qwen3.5 聊天模板：把消息拼成模型期待的格式

模型在训练时看到的消息有固定格式，推理时必须复刻。`src/Qwen35Sharp.Model/ChatTemplate.cs` 的 `RenderQwen35` 按角色拼模板（真实代码）：

```csharp
public static string RenderQwen35(
    IReadOnlyList<ChatMessage> messages,
    bool addGenerationPrompt = true,
    bool enableThinking = true)
{
    StringBuilder sb = new();
    int startIdx = 0;
    if (messages.Count > 0 && messages[0].Role == "system")     // 系统消息
    {
        sb.Append("<|system|>\n");
        sb.Append(messages[0].Content.Trim());
        sb.Append("\n<|/system|>\n");
        startIdx = 1;
    }

    for (int i = startIdx; i < messages.Count; i++)
    {
        ChatMessage msg = messages[i];
        if (msg.Role == "user")                                  // 用户消息
        {
            sb.Append("<|user|>\n");
            sb.Append(msg.Content.Trim());                       // user 要 Trim
            sb.Append("\n<|/user|>\n");
        }
        else if (msg.Role == "assistant")                        // 助手消息
        {
            sb.Append("<|assistant|>\n");
            sb.Append(msg.Content);                              // assistant 不 Trim！
            sb.Append("<|/assistant|>\n");
        }
    }

    if (addGenerationPrompt)                                     // 生成提示
    {
        sb.Append("<|assistant|>\n");
        if (enableThinking) sb.Append(" thinking\n");            // 打开思考块
        else                sb.Append(" thinking\n\n response\n\n");  // 空思考块（不思考）
    }
    return sb.ToString();
}
```

`ChatMessage` 是 `readonly record struct ChatMessage(string Role, string Content)`。三个值得品味的细节：**user 要 Trim、assistant 不 Trim**；**生成提示 `<|assistant|>\n thinking\n`**；**模板是纯文本**（无视觉占位，未来接视觉模型这里是要改的第一个地方）。

CLI 每次多轮把历史 `messages` 重新 `RenderQwen35` 再 `Tokenizer.Encode`——"历史即上下文"，也是 `KvCacheAlign`（第 10 章）前缀复用的原因：每轮前缀都一样，能命中缓存。

> **一句话总结这一章**：`BpeTokenizer` 用特殊 token 预拆分、预分词正则（`ResolvePreTokenizer`）、字节编码（`ByteEncode`/`EncodeByte`）、BPE 合并（`Bpe`）把文字可靠地编成 token id、再 decode 回来（`Decode`/`AppendTokenBytes`）；`ChatTemplate.RenderQwen35` 把消息拼成 `<|system|>/<|user|>/<|assistant|>` 结构并加生成提示。文字通了——只剩最后一件事：把一切装进能交互的程序，让模型真正开口说话。第 14 章，CLI 与自回归生成循环。
